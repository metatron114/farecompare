# farecompare · 车票机票比价搜索

> 输入出发地、目的地和日期，自动查询**火车票 + 机票**，把「直达 / 多线路中转 / 航铁联程」
> 的所有方案**按最低价排序**。本地运行，界面简洁，**零第三方依赖**（只用 Python 标准库）。

## 快速开始

### 环境要求

- **Python 3.10+**（<https://www.python.org/downloads/>）
- 抓取机票需要一个基于 Chromium 的浏览器：**Microsoft Edge**（Windows 自带）
  或 **Google Chrome**。没有也能运行，机票会降级为"参考价"并明确标注。
- 操作系统：Windows / macOS / Linux 均可（数据源站点在国内，网络需能访问它们）

### 方式一：直接运行（推荐）

```bash
git clone https://github.com/yourname/farecompare.git
cd farecompare

# Windows：双击 启动.bat
# macOS / Linux：
./start.sh

# 或者任意平台：
python run.py
```

浏览器会自动打开 <http://127.0.0.1:8765/>。

### 方式二：pip 安装

```bash
pip install -e .          # 开发安装（可编辑）
# 或
pip install .             # 正式安装
farecompare                # 启动
```

### 命令行用法

```bash
farecompare                          # 启动服务并打开浏览器
farecompare serve --port 8080        # 指定端口
farecompare serve --no-browser       # 不自动打开浏览器
farecompare serve --budget 60        # 提高单次搜索的 12306 请求上限

farecompare check                    # 环境与数据源自检（无需先启动服务）

farecompare fetch stations           # 更新铁路车站库（12306 官方站名表）
farecompare fetch gaotie --cities    # 更新客运车站目录（含每城完整列表）
farecompare fetch airports           # 更新民航城市库（需要 Edge）
farecompare fetch all                # 全部更新
```

自检与验收脚本：

```bash
python tools/selftest.py --api       # 17 项自检
python tools/acceptance.py           # 端到端验收（需先启动服务）
```

| 航铁联程 | 飞机 + 高铁组合（机场→火车站预留 90–420 分钟） |

点任意一天即可对该日做完整比价。

## 数据源

### 火车票

| 源 | 角色 | 说明 |
| --- | --- | --- |
| **gaotie.com.cn** | ✅ 主搜索通道 | 静态线路页直接给出两站间**全部车次 + 时刻 + 历时 + 经停数 + 票价**；无鉴权、无频率限制 |
| **12306** | ✅ 实时补充 | 实时余票与浮动折扣票价；仅在 gaotie 无线路页面时回落，单次搜索最多 4 个区间 |

> 12306 对短间隔连续请求会限流，"多车站 × 多枢纽"的全面搜索容易触顶。
> gaotie 承担大范围线路扫描，12306 只在必要时补充实时折扣 —— 因此
> **上海→北京 这类线路现在 1.3 秒返回、12306 请求 0 次**。

**票价口径**：gaotie 给的是铁路部门**公布票价**（全票），不含市场化浮动折扣；
界面会标注来源并提示"实时折扣以 12306 为准"。

### 机票

| 源 | 状态 | 说明 |
| --- | --- | --- |
| **同程旅行** | ✅ 实时 | 通过本机无头浏览器渲染列表页取得；含机型、航站楼、餐食、折扣 |
| 携程 | ⚠️ 保留接口 | 页面与接口有 `whaleguard` 反爬，无头浏览器一律被拦 |
| 去哪儿 | ⚠️ 保留接口 | 网页版机票服务已下线，接口需前端 `__m__`(SM4) 签名 |
| 内置参考价模型 | 兜底 | 实时源都失败时启用，界面明确标注 `○ 参考价` |

**裸票价口径**：只读列表页明码标价的机票价格，**从不点击**保险、接送机、加速包、
套餐等任何搭售项。机建燃油属强制税费，在"详情"里单独提示，不计入比价基准。

## 中转与联程规则

**火车中转**（一次换乘，整个行程只经过一个中间车站）：

1. 候选换乘城市按综合评分排序：

   ```
   评分 = 绕行里程 − 枢纽等级 × 300km − 走廊/省会加成 100km     （越小越优先）
   ```

   枢纽等级来自内置的**中国城市规划数据**（`china_geo.py`）：
   34 个省级行政区 → 省会映射、351 个城市 → 省份映射、142 个枢纽分三级。

2. **偏僻站点自动经省会中转**：输入 `瓦房店` 会先归一到 `大连`，再找辽宁省会 `沈阳`
   并把同省主要枢纽纳入候选。实测：

   ```
   喀什 → 北京   中转 ¥530  经 乌鲁木齐
        Y568  喀什→乌鲁木齐    00:15-16:58  ¥178
        Z180  乌鲁木齐→北京西  21:14-13:33  ¥352
   ```

3. 每个枢纽逐站探测（呼和浩特的车只到**北京北**，不是北京南），
   前段到站必须等于后段发站（按电报码校验）。
4. 同日换乘间隔 30–360 分钟；当天无接续时给出**隔夜换乘**
   （前段 22:00 前到达 + 次日 06:00–12:00 出发）。
5. 质量门：既不比直达便宜、又比直达慢 3 小时以上的中转会被丢弃。

**航铁联程**：枢纽需有民航机场；去程为实时机票（已过滤无托运），
接续为实时车票，**换乘间隔 90–420 分钟**，界面提示"落地后需自行前往火车站"。

## 车站库

### 客运车站目录

12306 官方站名表（3396 站）**不区分客货运**，混有 `广州西`、`石牌`、`白云湖`、
`双流西` 等货运/编组站。程序接入
**[高铁网 · 全国铁路客运车站大全](https://www.gaotie.com.cn/huochezhan/)** 作为权威目录：

| 项目 | 数量 |
| --- | --- |
| 客运目录车站 | 5710 |
| 覆盖城市（行政区划） | 346 |
| 与 12306 站名表匹配 | 3367 |
| **识别并剔除的非客运站** | **30** |

**三重过滤**：① 客运目录（主）→ ② 实测学习（余票接口返回过的车站自动标记为客运站）→
③ 手工屏蔽名单（`cache/blocked_stations.json`）。目录文件缺失时自动降级为保守保留。

### 城市 → 车站 子分组

## HTTP 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 前端页面 |
| GET | `/api/suggest?q=&grouped=1` | 车站/城市分组联想 |
| GET | `/api/stations?city=` | 某城市的客运车站列表 |
| POST | `/api/search` | 单日比价搜索，返回 `task_id` |
| POST | `/api/range` | 日期区间每日最低价 |
| GET | `/api/progress?task_id=` | 查询进度 |
| GET | `/api/result?task_id=` | 取结果 |
| GET | `/api/health` | 各数据源健康状态 |

## 性能与限流

| 场景 | 纯 12306 方案 | 本项目 |
| --- | --- | --- |
| 上海→北京 直达 | 37 秒 / 26 次请求 | **1.3 秒 / 0 次请求** |
| 北京→广州 全量比价 | 38 秒 | **9 秒** |
| 喀什→北京 中转 | 60+ 次请求 | **3 秒 / 0 次请求** |

12306 通道的限流保护（仅在必要时使用）：

- 串行请求，最小间隔 **1.2 秒**；
- **全局速率闸门**：60 秒内最多 55 次请求（滑动窗口）；
- 命中限流即进入**全局冷却**（20/30/40 秒递增），可在 `/api/health` 查看冷却次数；
- 单次搜索请求预算 35 次（`--budget` 可调），中转另有软配额；
- 结果按（出发地+目的地+日期+开关）缓存 10 分钟。

机票抓取使用**常驻无头浏览器**（单线程队列），一次列表约 4–7 秒；
浏览器被外部关闭或崩溃时会**自动重建并重试**。

## 隐私说明（重要）

程序**不会上传任何数据**，全部在本机处理。有两点需要你知晓：

1. **`cache/cookies.json` 包含你的登录态，已在 `.gitignore` 中排除，请勿提交到公开仓库。**
   `firefox_cookies.py` 会从本机火狐**只读**复制一份 Cookie 数据库，仅提取
   12306 / 携程 / 去哪儿 / 同程这几个域，用于需要登录的接口。删除该文件即可停用，
   程序会自动降级为不携带登录态。
2. 抓取浏览器使用独立配置目录（`cache/edge-profile/`），不读取、不影响你日常浏览器的配置。

## 已知限制

1. 火车中转仅支持**一次换乘**（按要求限定为只经过一个中间车站）。
2. 12306 部分区间/日期未到起售时间会返回占位行，程序会识别并提示换更近日期。
3. gaotie 票价为公布票价，实时折扣请以 12306 为准。
4. 机票价格为列表页裸票价，**不含机建燃油**（约 ¥50–120，属强制税费）。
5. 携程、去哪儿当前取不到实时机票（原因见"数据源"），已保留接口，可达时自动启用。
6. 机票抓取依赖本机 Edge/Chrome；无法启动时会降级到参考价并标注。
7. 预售期约 60 天；区间搜索最长 60 天。
8. 隔夜换乘需要在中转城市住宿，请自行评估。
